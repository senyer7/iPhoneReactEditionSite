# iPhoneReactEditionSite 🍏

## О проекте
**iPhoneReactEditionSite** — это современный веб-сайт, созданный с использованием React, вдохновленный дизайном и эстетикой iPhone. Проект демонстрирует возможности React в создании интерактивных и визуально привлекательных веб-приложений.

![iPhoneReactEditionSite](https://example.com/preview.png)

## Особенности проекта

* **Современный дизайн**: вдохновлен последними версиями iOS
* **Интерактивные компоненты**: использование React для создания динамичных элементов
* **Адаптивность**: полная поддержка мобильных устройств
* **Оптимизация**: быстрая загрузка и производительность

## Технологии

* **React**: для создания пользовательского интерфейса
* **CSS Modules**: для стилизации компонентов
* **Tailwind CSS**: эффективный фреймворк CSS.


## Установка

Для запуска проекта выполните следующие команды:

```bash
# Клонирование репозитория
git clone https://github.com/senyer7/iPhoneReactEditionSite.git

# Переход в директорию проекта
cd iPhoneReactEditionSite

# Установка зависимостей
npm install

# Запуск проекта
npm run dev
